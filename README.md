# Lead CRM – Single Page Website

A **fully responsive single-page website** converted **from Figma design to code** using **React** and **Tailwind CSS**.  
This project focuses on **pixel-perfect UI**, clean component structure, and modern frontend best practices.

---

## ✨ Overview

This project is a **static single-page website** designed for a Lead CRM product.  
The UI was implemented directly from a **Figma design**, ensuring accurate spacing, typography, colors, and layout across all screen sizes.

---

## 🎯 Key Highlights

- 🎨 Pixel-perfect **Figma to React conversion**
- 📱 Fully responsive (Mobile, Tablet, Desktop)
- 🧩 Reusable React components
- 💨 Utility-first styling with Tailwind CSS
- ⚡ Fast and lightweight single-page setup
- 🖼 Optimized images and icons
- ♿ Accessible and semantic HTML structure

---

## 🛠 Tech Stack

- **Framework:** React
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Build Tool:** Vite / CRA
- **Design Source:** Figma
